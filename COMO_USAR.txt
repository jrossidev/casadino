CASA DO DINOSSAURO - SITE COM PAINEL CORRIGIDO

IMPORTANTE:
O painel /admin NÃO salva alterações se o site for publicado apenas arrastando ZIP/manual deploy na Netlify.
Para funcionar corretamente, publique o projeto pelo GitHub e conecte o repositório na Netlify.

PASSO A PASSO RECOMENDADO:
1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste projeto para o repositório.
3. Na Netlify, crie um novo site importando esse repositório.
4. Build command: deixe vazio.
5. Publish directory: .
6. Depois do deploy, vá em Identity e ative o Netlify Identity.
7. Em Registration, use Invite only.
8. Ative o Git Gateway.
9. Convide o e-mail do cliente.
10. O cliente cria a senha pelo convite e acessa /admin.

O QUE FOI CORRIGIDO:
- Removido aviso preso de "Carregando painel".
- Mídia agora mostra imagens reais, não só .gitkeep.
- Conteúdo das páginas virou editável pelo painel.
- Unidades, horários, WhatsApp, textos, seções, cards e galerias podem ser editados.
- O convite de usuário abre o Identity corretamente e redireciona para /admin.

ONDE EDITAR:
/admin -> Configurações gerais: logo, WhatsApp, telefone, horários, unidades e redes sociais.
/admin -> Páginas do site: topo, textos, seções, cards, galerias e chamada final de cada página.

OBSERVAÇÃO:
Se o repositório usar branch master em vez de main, edite admin/config.yml e troque:
branch: main
por:
branch: master
